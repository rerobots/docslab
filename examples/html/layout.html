The examples below use the special hardshare owner "test", so no real hardware is used. Each sandbox includes a Python runtime.

The default layout begins with the code editor and, while running, stacks new items like the terminal underneath it.

Try it 
print("hola")

If data-layout="tabs" is added to the docslab div, then new items like the terminal are shown in separate tabs. This layout is intended to keep the page size constant, so the docslab sandbox does not affect styling and space used by content below it.

Try it
